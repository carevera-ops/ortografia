# Tildín · Ortografía y acentuación

App (PWA) para practicar ortografía y, sobre todo, acentuación en español, pensada para instalarse en un iPhone.
Funciona sin conexión, sin cuentas y sin enviar datos a ningún sitio.

> 🚧 En desarrollo. El README completo (instalación en el iPhone, copias de seguridad, recordatorios…) llegará al final.

## Desarrollo rápido

```bash
npm install
npm run dev        # servidor de desarrollo
npm run build      # tipos + tests + build de producción
npm run preview    # sirve la versión compilada (con service worker)
npm run test:e2e   # pruebas E2E (PW_BROWSER=chromium si no tienes WebKit)
```
