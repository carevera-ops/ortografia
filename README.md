# Tildín · Ortografía y acentuación

**Tildín** es una aplicación para practicar ortografía y, sobre todo, **acentuación** en español, pensada para un niño o una niña de 6.º de Primaria o 1.º de ESO (España). Funciona como las apps de idiomas: lecciones cortas, un camino de unidades, rachas, insignias… y se instala en el iPhone como si fuera una app normal.

- 📱 Se instala desde Safari en la pantalla de inicio y se abre a pantalla completa.
- ✈️ Funciona **sin conexión** después de la primera carga.
- 🔒 **Sin cuentas, sin anuncios, sin analítica y sin enviar datos a ningún sitio**: todo se guarda en el propio iPhone.
- 📚 Más de **4.300 preguntas** revisadas según la *Ortografía de la lengua española* (RAE, 2010), de las que más de 3.300 son de acentuación.

**Dirección de la app:** <https://carevera-ops.github.io/ortografia/>

## Qué incluye

**Temario** (23 unidades, en orden de dificultad):

| Bloque | Unidades |
|---|---|
| **Acentuación** | Sílabas · Sílaba tónica · Agudas, llanas y esdrújulas · Tilde en agudas · Tilde en llanas · Esdrújulas y sobresdrújulas · Casos especiales (*bíceps, robots, virrey*) · Diptongos y triptongos · Hiatos (*país, búho, reír*) · Monosílabos (*fue, dio, guion*) · Tilde diacrítica (*tú/tu, él/el, sí/si…*) · Interrogativos y exclamativos · *Por qué / porque / porqué / por que* · *Solo* y demostrativos · *-mente*, compuestos y pronombres pegados · Mayúsculas con tilde y gran repaso |
| **Ortografía general** | B/V y M antes de P y B · G/J · H · LL/Y y R/RR · C/Z/S/X · Homófonos (*hay/ahí/ay, haber/a ver, echo/hecho…*) · Mayúsculas y puntuación (¿ ¡) |

**Tipos de ejercicio:** elegir la forma correcta, tocar la vocal que lleva tilde, tocar la sílaba tónica, clasificar, separar en sílabas, completar el hueco, encontrar la palabra mal escrita, diptongo o hiato, explicar la regla, «¿qué frase tiene bien todas las tildes?» y **dictado** con voz (palabras y frases).

Después de cada respuesta aparece la forma correcta y una explicación breve; el botón **Ver regla** abre la ficha de teoría.

**Dificultad que se adapta:**

- Cada pregunta tiene una dificultad de 1 a 5 y la app calcula el dominio de cada tema.
- **Si acierta varias seguidas, las siguientes preguntas son más difíciles** («⚡ ¡Vas tan bien que subimos el nivel!»); si falla dos seguidas, baja un poco.
- **Prueba de nivel** en cada unidad: con un 85 % se salta la unidad. Con un 100 % en un nivel, se puede ir directamente al repaso final.
- Lo que se falla vuelve a salir al final de la lección y en los días siguientes (repetición espaciada).

**Motivación:** XP, racha diaria con protectores 🧊, objetivo diario, felicitación de **día de campeón** (20 minutos con más del 90 % de aciertos), 18 insignias y la pantalla **Mi progreso** (minutos por día, calendario, aciertos por tema y «palabras que más me cuestan»). Se puede estudiar todo el tiempo que se quiera: no hay vidas ni esperas.

## Instalación en el iPhone

1. Abre **Safari** (tiene que ser Safari, no Chrome ni otro navegador).
2. Entra en <https://carevera-ops.github.io/ortografia/>. Saldrá la pantalla «¡Instala Tildín en tu iPhone!».
3. Toca el botón **Compartir** (el cuadrado con una flecha hacia arriba, abajo en el centro).
4. Desliza el menú hacia arriba y toca **«Añadir a pantalla de inicio»**. Después, **«Añadir»**.
5. A partir de ahora, **abre Tildín siempre desde su icono** de la pantalla de inicio.

> ℹ️ La app instalada y Safari guardan los datos por separado. Si se estudia en Safari, ese progreso **no** pasa a la app instalada. Usa siempre el icono.

> 🎧 Para el **dictado** hace falta una voz en español: Ajustes → Accesibilidad → Contenido leído → Voces → Español (España). Si el iPhone no tiene voz española, el dictado no aparece.

## Cómo actualizar la app en el iPhone

Cuando se publica una versión nueva:

1. Abre Tildín desde su icono **con conexión a internet**.
2. Aparecerá arriba el aviso **«✨ Hay una versión nueva»** → toca **Actualizar**.
3. Si no sale el aviso, cierra la app del todo (desliza hacia arriba desde el selector de apps) y vuelve a abrirla una o dos veces.

El progreso no se pierde al actualizar.

## Zona de padres

Se entra con el botón ⚙️ del Inicio y está protegida con un **PIN de 4 números** (se crea la primera vez). Incluye:

- **Resumen de la semana:** tiempo, días con estudio, lecciones, aciertos, racha y los temas más fuertes y más flojos.
- **Ajustes:** qué cuenta como día de racha (una lección o 5 minutos, solo lección o solo minutos), objetivo diario, tema claro/oscuro y sonido.
- **Desbloquear todas las unidades:** abre todo el camino para practicar lo que se quiera (el progreso se sigue guardando).
- **Seguimiento desde otro dispositivo**, **copia de seguridad**, **recordatorio con Atajos**, **cambiar el PIN** y **reiniciar el progreso** (hay que escribir BORRAR para confirmar).

Si se olvida el PIN, en la propia pantalla hay una opción para quitarlo sin perder el progreso. El PIN es una barrera para que el niño no cambie los ajustes sin querer, no una medida de seguridad fuerte.

## Copia de seguridad del progreso

> ⚠️ **Importante:** todo el progreso se guarda **solo en el iPhone, dentro de la app instalada**. **Si se borra el icono de la pantalla de inicio, se borra el progreso.** También se pierde si se cambia de iPhone sin hacer una copia.

**Hacer una copia:**

1. Zona de padres → **Copia de seguridad** → **📤 Exportar copia**.
2. Se abre la hoja de compartir del iPhone: elige **Guardar en Archivos** (por ejemplo, en iCloud Drive), o envíatela por correo o WhatsApp.
3. El archivo se llama `tildin-copia-AAAA-MM-DD.json`.

La app recuerda hacer una copia cada dos semanas (en el Inicio y en la zona de padres).

**Restaurar una copia:**

1. Instala Tildín (si hace falta) y ábrelo desde el icono.
2. Zona de padres → **Copia de seguridad** → **📥 Restaurar una copia** y elige el archivo.
3. La app muestra de qué fecha es la copia y cuántos días, lecciones y XP tiene. Toca **Restaurar**. El progreso actual se sustituye por el de la copia.

## Seguimiento desde otro dispositivo

Sirve para que madres y padres vean la evolución desde su propio móvil, **sin servidores ni cuentas**.

1. En el iPhone del niño: Zona de padres → **Seguimiento desde otro dispositivo**. Si quieres, escribe un nombre o apodo para el informe y toca **📲 Generar código de seguimiento**.
2. Aparece un **código QR**: escanéalo con la cámara de tu móvil. También puedes tocar **🔗 Compartir enlace** y enviártelo.
3. En tu móvil se abre el informe: semana, racha, minutos de las últimas 4 semanas, aciertos por tema y palabras que más le cuestan.
4. Toca **💾 Guardar para ver la evolución**. Repítelo cada semana para ver cómo avanza en **Ver informes guardados** (se pueden seguir varios niños: cada uno tiene su código).

**Privacidad:** los datos van **dentro del propio enlace**, en la parte que hay detrás de `#`, que los navegadores nunca envían al servidor. El informe es una «foto» del momento en que se genera; para verlo actualizado, genera un código nuevo.

## Recordatorio diario con la app Atajos

Una web app no puede enviar notificaciones por sí sola, pero la app **Atajos** del iPhone sí:

1. Abre **Atajos** → pestaña **Automatización** → **+** (Nueva automatización).
2. Elige **Hora del día**, pon la hora (por ejemplo, 18:00) y marca **Diariamente**.
3. Marca **Ejecutar inmediatamente** y pulsa **Siguiente**.
4. Añade la acción **Mostrar notificación** con un texto como «¡Hora de practicar con Tildín! 🔥». Si quieres, añade también **Abrir app** y elige Tildín.
5. Pulsa **OK**.

Además, el Inicio de Tildín muestra «¡Tu racha de N días te espera!» si ese día aún no se ha estudiado.

## Para quien mantiene la app: requisitos y uso en el PC

**Requisitos** (en Windows, macOS o Linux):

- [Node.js LTS](https://nodejs.org/) (versión 22 o superior).
- [Git](https://git-scm.com/).
- Una cuenta gratuita de [GitHub](https://github.com/).

**Descargar el proyecto y ejecutarlo** (en la terminal, PowerShell en Windows):

```bash
git clone https://github.com/carevera-ops/ortografia.git
```

```bash
cd ortografia
```

```bash
npm install
```

```bash
npm run dev
```

Abre en el navegador la dirección que aparece (normalmente <http://localhost:5173/ortografia/>). Para probarla en el iPhone conectado a la misma wifi, usa la dirección «Network» que muestra la terminal.

**Otras órdenes útiles:**

| Orden | Qué hace |
|---|---|
| `npm run build` | Comprueba los tipos, pasa todos los tests (incluida la validación del banco de preguntas) y genera la versión final en `dist/` |
| `npm run preview` | Sirve la versión final (con modo sin conexión) para probarla |
| `npm test` | Tests unitarios |
| `npm run test:e2e` | Pruebas de extremo a extremo con emulación de iPhone (WebKit; usa `PW_BROWSER=chromium` si no tienes WebKit instalado) |
| `npm run bank` | Regenera el banco de preguntas a partir de las listas de `content-src/` |
| `npm run icons` | Regenera los iconos PNG a partir del SVG |

## Cómo publicar y actualizar

La app se publica gratis en **GitHub Pages**. Cada vez que se sube un cambio a la rama `main`, GitHub compila la app, pasa todos los tests (también en WebKit, el motor de Safari) y la publica.

```bash
git add -A
```

```bash
git commit -m "Describe aquí el cambio"
```

```bash
git push
```

- El progreso de la publicación se ve en la pestaña **Actions** del repositorio: <https://github.com/carevera-ops/ortografia/actions>.
- Tarda unos 3 minutos. Si algún test falla, **no se publica** (la versión anterior sigue funcionando).
- La dirección es siempre <https://carevera-ops.github.io/ortografia/>.

**Configuración inicial (solo una vez):** en GitHub, *Settings → Pages → Build and deployment → Source:* **GitHub Actions**.

> En una cuenta gratuita, el repositorio de GitHub Pages es **público**. El código no contiene ningún dato personal y el progreso del niño nunca sale de su iPhone.

## Cómo está hecha

- **Vite + React + TypeScript** (modo estricto) y **vite-plugin-pwa** (Workbox) para funcionar sin conexión.
- **IndexedDB** (Dexie) para guardar el progreso en el dispositivo.
- **Módulo de fonología del español** propio (`src/core/phonology`): separación silábica, sílaba tónica y reglas de la tilde. Con él se **valida automáticamente cada pregunta del banco** en cada publicación.
- El banco se genera desde listas de palabras y frases revisadas a mano (`content-src/`) y se guarda en `public/content/*.json`.
- Más de 240 tests unitarios (Vitest) y 37 pruebas de extremo a extremo (Playwright con WebKit y emulación de iPhone), incluidas revisiones automáticas de accesibilidad (axe, WCAG 2.1 AA) en modo claro y oscuro.
